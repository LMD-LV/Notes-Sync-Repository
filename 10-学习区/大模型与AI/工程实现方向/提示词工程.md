ai思维链，本质是根据训练数据进行模式匹配
任务泛化 **指模型能把在一种任务上学到的推理模式，应用到另一种任务上。任务泛化失败**说明，模型学到的可能只是“分步解题”的**表层任务模式**，而非深层逻辑。 
长度泛化 **指模型是否能解决比训练数据中见过的任何例子都更长的推理问题。****长度泛化失败**说明，模型可能只是在回忆见过的**答案模板的覆盖范围**，而非掌握运算法则。
格式泛化 **指模型对推理步骤的呈现格式是否敏感，能否在格式被破坏后依然保持推理能力。** 1**格式泛化失败**说明，模型高度依赖**输出结构的“语法糖”**，而非理解推理的内在结构。

思维链很可能是大模型在海量数据中，涌现出的一种极其精巧、高度抽象的**模式匹配与序列生成能力**，它无比强大，以至于能在大多数常见场景下完美模拟推理，但它和我们人类以因果逻辑为基础的符号推理，底层机制可能有根本不同。




Skills
 
 是一种**自然语言指令文件**，通常是 Markdown 格式，用来教 Agent"在什么场景下、按照什么方法、遵循什么规范来完成特定任务"。
一个完整的skill 由 SKILL.md, references,scripts 组成
实际被使用的时候, 根据用户输入语义与 Skill 的 name 和 description 进行向量化匹配，筛选出可能相关的 Skill, 将召回的 Skill 提供给大模型，由模型结合上下文选择最合适的 Skill
由Agent来执行加载, 采用 **按需加载** 的方式。Agent 通常会先读取 `SKILL.md` 中的能力说明和执行规则，以理解该 Skill 的整体能力,只有在任务确实需要时，才会进一步读取 `references/` 中的内容，或选择性执行 `scripts/` 中的脚本。
这种方式被称为 **渐进式加载（Progressive Disclosure）**，可以避免一次加载大量无关信息，从而降低上下文复杂度并提升推理效率。

skill md通过拆分子文件的方式，减少对上下文的占用
1. 以 SKILL.md 为核心的知识文档：通过自然语言逻辑 (metadata+文档索引)，建立一个树层级的知识文档体系。LLM 在面对任务时，先基于高层次文档 判断此次任务涉及的相关知识文档 (Discovery)；再在必要时 动态要求客户端索引&读取相关文档 (Activation)。这样就可以过滤和任务无关的信息，减少完成任务的上下文数量。 
2. 包含在 skills 体系中的脚本工具：知识文档中除了自然语言形式的任务指导，也会包含一些领域任务工具的使用说明（包括 MCP），扩展 LLM 在领域任务的规范化能力。这些领域任务工具可以以“脚本文件&程序片段”的形式直接由用户以 静态形式给出 (Hard-coded Tools)，也可以由 LLM 基于知识文档中提供的信息（库依赖、现有函数工具）针对当前任务来 动态生成 (LLM as a Creator)。
