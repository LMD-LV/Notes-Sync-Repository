## 模型的基本分类

根据模型性质，可以分为概率模型/非概率模型，线性/非线性模型等。
按照常规方式分类: 有监督,无监督, 半监督, 强化学习

## 机器学习模型的 “应用场景 + 核心任务” 双维度分类 ##

1. 线性回归模型：用于探索变量之间的线性关系，通常用于预测数值型数据。
2. 逻辑回归模型：用于解决二分类问题，将数据映射到一个逻辑函数中，输出0或1。
3. 决策树模型：通过树状结构表示决策规则，易于理解和解释，适用于分类和回归问题。
4. 随机森林模型：由多个决策树组成的集成学习算法，提高了预测准确性和泛化能力。
5. 支持向量机模型：寻找最优超平面将不同类别的数据分隔开，适用于分类和回归问题。
6. 聚类模型：如K均值聚类、层次聚类等，用于将数据分成不同的组别。
7. 关联规则模型：用于发现数据中的频繁项集和关联规则，常用于市场篮分析等领域。
8. 主成分分析（PCA）：用于降维，提取数据中的主要特征，减少数据的复杂度。
9. 神经网络模型：如深度学习模型，通过多层神经元构建复杂的非线性模型，适用于复杂数据。
10. 文本挖掘模型：如自然语言处理（NLP）模型，用于分析和理解文本数据。
11. 时间序列模型：如ARIMA模型、LSTM模型等，用于分析时间序列数据的趋势和周期性。
12. 协同过滤模型：常用于推荐系统，通过用户行为数据预测用户的偏好。
13. 贝叶斯网络模型：用于表示变量之间的概率关系，进行概率推断和决策分析。
14. 强化学习模型：通过与环境的交互学习最优策略，常用于游戏和控制领域。
15. 遗传算法模型：基于生物进化原理设计的优化算法，用于求解复杂问题的最优解。



## 机器学习范式总览

| 术语                     | 大类       | 核心思路（含典型算法/模型）                                                   | 手工特征需求                      | 适用场景                     | 优劣                        |
| ---------------------- | -------- | ---------------------------------------------------------------- | --------------------------- | ------------------------ | ------------------------- |
| **监督学习**               | 广义       | 有标签数据，用标签指导模型学习映射关系（线性回归、逻辑回归、SVM、决策树、XGBoost、神经网络等）             | 需要：输入是数值/编码后的特征向量（可手工特征）    | 标签充足的预测任务，如分类、回归、评分预测    | ✅ 精度高、可解释性强；❌ 标签依赖重、标注成本高 |
| **无监督学习**              | ML 分支    | 无标签，挖掘数据内部结构或分布（聚类 K-means、谱聚类；降维 PCA、t-SNE、UMAP；密度估计）           | 需要：手工或自动提取特征（尺度、归一化很重要）     | 客群划分、异常检测、降维可视化、特征压缩     | ✅ 无需标签、探索性强；❌ 结果不唯一、难评估   |
| **半监督学习**              | ML 策略    | 少量有标注 + 大量无标注，联合利用（自训练、图半监督、伪标签、Consistency regularization）      | 需要：与监督一样的特征表示，且能评价无标注样本可靠度  | 标签稀缺、获取成本高的场景（医学影像、安防检测） | ✅ 节省标注成本；❌ 伪标签噪声易传播       |
| **自监督学习**              | ML 分支    | 通过预text任务从无标签数据学表征（掩码语言模型、对比学习、旋转预测等；BERT、SimCLR）                | 通常用原始信号（文本、图像、时间序列），少依赖人工特征 | 大规模无标签数据，如文本、语音、视频表征学习   | ✅ 表征能力强、通用性高；❌ 训练成本高      |
| **深度学习**               | ML 学派    | 用多层神经网络端到端学习表示与任务（CNN、RNN/Transformer、ResNet等）                   | 少量手工特征可行，常直接用原始数据           | 视觉识别、语音识别、NLP、推荐系统       | ✅ 自动提取特征、强拟合；❌ 数据/算力需求高   |
| **神经网络**               | 模型族      | 可微分函数族，靠反向传播学习权重，灵活可构建复杂架构                                       | 可从原始特征自动学习表示                | 任意非线性复杂映射问题              | ✅ 表达能力强；❌ 调参复杂、可解释性弱      |
| **迁移学习**               | 策略/范式    | 利用预训练模型迁移到新任务（微调、特征提取；如 FinBERT、ImageNet 模型）                     | 可减少手工特征需求                   | 小样本、跨领域任务，如医学、金融NLP      | ✅ 快速收敛、小样本优势；❌ 领域偏差风险     |
| **强化学习（RL）**           | 学派       | 通过与环境交互、试错学习策略以最大化累积回报（Q-learning、Policy Gradients、Actor-Critic） | 需要状态与动作空间特征                 | 自动控制、游戏AI、推荐系统动态策略       | ✅ 自主决策强；❌ 收敛慢、需大量交互       |
| **主动学习**               | ML 策略    | 选择最有价值样本去标注以减少标注成本（不确定性采样、基于模型的）                                 | 需要模型可输出不确定度                 | 数据标注昂贵的场景（医学、安防、金融）      | ✅ 降低标注成本；❌ 依赖初始模型质量       |
| **增量学习 / 在线学习**        | ML 策略    | 模型能持续接收新数据并更新（SGD、流式树、在线SVM）                                     | 需要一致特征表示                    | 实时系统、监控流数据、广告推荐          | ✅ 实时更新、资源高效；❌ 易灾难遗忘       |
| **集成学习**               | 方法       | 组合多个基学习器以提升精度（Bagging、Boosting、Stacking）                         | 与基模型相同特征需求                  | 分类回归泛用，如信用评分、竞赛模型        | ✅ 精度高、鲁棒性强；❌ 可解释性弱、训练慢    |
| **表示学习 / 特征学习**        | 目标/范式    | 自动学出低维/语义表示（自编码器、深度嵌入）                                           | 通常从原始信号学习                   | 降维、特征压缩、预训练表征            | ✅ 降维可视化好；❌ 训练不稳定          |
| **对比学习**               | 自监督/表示学习 | 拉近正样本对、推远负样本对（SimCLR、MoCo、InfoNCE）                               | 多用原始信号与增强                   | 图像/文本嵌入、检索表征             | ✅ 泛化好；❌ 需大批量样本与算力         |
| **元学习（Meta-learning）** | 高阶学习     | 学习如何快速从少样本中泛化（MAML、ProtoNet、Reptile）                             | 对手工特征依赖少                    | 小样本学习、跨任务迁移              | ✅ 少样本强；❌ 实现复杂、计算重         |
| **少样本 / 零样本学习**        | 能力/策略    | 样本极少或无样本时泛化（few-shot、zero-shot）                                  | 依赖好表示                       | 新类别识别、跨语言迁移              | ✅ 样本效率高；❌ 泛化仍有限           |
| **生成模型**               | 模型族      | 学习数据分布并生成样本（VAE、GAN、Diffusion）                                   | 常用原始信号                      | 图像生成、语音合成、数据增强           | ✅ 创造力强；❌ 稳定性差、评估难         |
| **图学习 / 图神经网络（GNN）**   | 模型族      | 利用图结构传播与聚合信息（GCN、GAT、GraphSAGE）                                  | 需要节点/边特征                    | 社交网络、分子结构、推荐系统           | ✅ 结构信息强；❌ 训练复杂、扩展性差       |
| **贝叶斯 / 概率模型**         | 学派       | 显式建模不确定性与先验（贝叶斯回归、朴素贝叶斯、HMM）                                     | 通常手工设计特征                    | 小样本推理、风险预测               | ✅ 可解释性好；❌ 模型灵活性低          |
| **因果学习 / 因果推断**        | 学派       | 关注因果关系而非相关（因果图、工具变量、因果发现）                                        | 需结构化特征与外部信息                 | 政策评估、医学实验、经济决策           | ✅ 解释强、可靠推断；❌ 数据要求高        |
| **弱监督学习**              | 策略       | 用粗标签或规则训练（distant supervision、label propagation）                 | 需规则/启发式标签源                  | 标签成本高场景（舆情、命名实体识别）       | ✅ 标注效率高；❌ 噪声大、精度有限        |
| **联邦学习**               | 隐私/分布式   | 多方本地训练聚合模型参数，保护隐私                                                | 需统一特征schema                 | 医疗、金融、跨组织协作              | ✅ 隐私友好；❌ 通信与同步开销大         |
| **知识蒸馏 / 模型压缩**        | 模型工程     | 用大模型教小模型（teacher → student）                                      | 手工特征可辅助                     | 模型部署、边缘计算                | ✅ 模型轻量快；❌ 需高质量teacher     |
| **多任务学习**              | 学派/策略    | 同时学习多个相关任务共享表示                                                   | 需统一特征                       | 共享输入的多输出任务（NLP多标签、推荐）    | ✅ 泛化好、节省数据；❌ 任务冲突风险       |



迁移学习是机器学习中的一种策略：它不是 “从零开始” 训练模型，而是**利用已有的知识（从其他任务 / 领域学到的经验）来解决新的任务 / 领域问题**。预训练模型的 “知识” 和它训练时用的数据密切相关。不同领域有其独特的语言风格、专业术语和逻辑规则（比如金融领域有 “风控、连带责任、财报” 等术语，医疗领域有 “病灶、处方药、半衰期” 等术语）。- 而**相近领域预训练的模型**（如 FinBERT，基于金融文本预训练）已经 “见过” 大量该领域的专业内容，提前学会了领域内的语义逻辑、术语搭配等知识。


#### 强化学习 (Reinforcement Learning - RL)

- **核心思路：** 智能体 (Agent) 在一个环境 (Environment) 中，通过不断地**试错**和**互动**，根据从环境接收到的**奖励 (Reward)** 信号，学习一个最优的**策略 (Policy)**，以决定在给定状态下应该采取什么动作 (Action)，从而最大化其长期累积奖励。
    
- **手工特征需求：**
    
    - **环境状态的表示 (State Representation)：** 这可以是原始观察值（如图像、传感器读数），也可以是经过特征工程提炼的数值特征向量。好的状态表示对于智能体学习是至关重要的。
        
    - **奖励函数的设计：** 奖励函数需要人工设计，明确智能体的目标，并引导其学习正确的行为。奖励设计是强化学习中的关键挑战之一。
        
- **适用场景：**
    
    - **决策制定：** 机器人控制、自动驾驶、游戏AI（Go, StarCraft等）。
        
    - **资源调度：** 数据中心能源管理、交通信号灯优化。
        
    - **金融交易：** 自动交易策略、投资组合优化（将交易动作视为智能体的动作，收益视为奖励）。
        
    - **个性化推荐：** 根据用户反馈（点击、购买）实时调整推荐策略。

#### 集成学习 (Ensemble Learning)

- **核心思路：** 不使用单个模型进行预测，而是构建并结合**多个学习器**（通常称为基学习器或弱学习器，可以是决策树、支持向量机、神经网络等），通过某种策略（如投票、加权平均、堆叠）来获得最终的预测结果。其目标是利用多个模型的“集体智慧”来减少偏差 (bias) 或方差 (variance)，从而提高模型的准确性和鲁棒性。
    
- **手工特征需求：**
    
    - **基学习器所需的特征：** 每个参与集成的基学习器仍然需要其对应的输入特征。这些特征可以是原始特征，也可以是经过转换或选择的特征子集。
        
    - **特征多样性（可选）：** 有时为了增加基学习器的多样性，会为不同的基学习器提供不同的特征子集。
        
- **常见方法：**
    
    - **Bagging (Bootstrap Aggregating)：** 独立训练多个基学习器，然后对它们的预测结果进行平均或投票。代表算法有**随机森林 (Random Forest)**。
        
    - **Boosting：** 顺序训练多个基学习器，每个新的学习器都试图纠正前一个学习器的错误。代表算法有 **AdaBoost, Gradient Boosting (GBDT)**，以及在此基础上的 **XGBoost, LightGBM, CatBoost**。
        
    - **Stacking (Stacked Generalization)：** 训练一个元学习器 (Meta-learner) 来结合多个基学习器的预测结果。基学习器的输出作为元学习器的输入。
        



#### 自监督学习中的常见前置任务：

自监督学习的具体实现通常依赖于巧妙设计的“前置任务”，这些任务使得模型能够在没有人工标注的情况下学习到有用的特征表示。

- **NLP领域（如BERT的预训练任务）:**
    
    - **Masked Language Model (MLM):** 随机遮蔽输入文本中的一些词，让模型预测被遮蔽的词。
        
    - **Next Sentence Prediction (NSP):** 给模型两个句子，让它判断第二个句子是否是第一个句子的下一句。
        
- **CV领域：**
    
    - **图像修复 (Inpainting):** 遮蔽图像的一部分，让模型预测缺失的像素。
        
    - **图像着色 (Colorization):** 将灰度图像转换为彩色图像。
        
    - **对比学习 (Contrastive Learning - SimCLR, MoCo等):** 通过最大化同一图像不同增强视图之间的一致性，最小化不同图像视图之间的一致性来学习表示。
