##### 评估指标

###### confuse matrix 混淆矩阵

矩阵的**行代表实际类别**，**列代表模型预测的类别**，每个单元格的值表示 “实际为 A 类却被预测为 B 类” 的样本数量。
二分类（只有 “正类” 和 “负类”）的混淆矩阵是 2×2 矩阵，定义了 4 个核心指标：

|           | 预测为正类(positive) | 预测为负类(negative) |
| --------- | --------------- | --------------- |
| **实际为正类** | TP（真阳性）：正确预测为正类 | FN（假阴性）：错误预测为负类 |
| **实际为负类** | FP（假阳性）：错误预测为正类 | TN（真阴性）：正确预测为负类 |
当有 N 个类别时，混淆矩阵是 N×N 矩阵
- 对角线元素是**正确预测的数量**，值越高说明该类预测越准；

|           | 预测为 A   | 预测为 B            | 预测为 C            |
| --------- | ------- | ---------------- | ---------------- |
| **实际为 A** | A→A（正确） | A→B（错误：A 被误判为 B） | A→C（错误：A 被误判为 C） |
| **实际为 B** | B→A（错误） | B→B（正确）          | B→C（错误）          |
| **实际为 C** | C→A（错误） | C→B（错误）          | C→C（正确）          |

###### accuracy
**准确率, 预测正确的结果占总样本的百分比**
计算公式为:
Accuracy=(TP+TN)/(TP+TN+FP+FN)
对角线

###### precision
精确率, 又叫**查准率**，它是**针对预测结果**而言的，它的含义是**在所有被预测为正的样本中实际为正的样本的概率**
Precision=TP/(TP+FP)
精准率代表对正样本结果中的预测准确程度，而准确率则代表整体的预测准确程度，既包括正样本，也包括负样本。

##### recall	
又叫**查全率**,**在实际为正的样本中被预测为正样本的概率**
Recall=TP/(TP+FN)

**精确率和召回率是一对此消彼长的度量**

###### fl-score

	F1 分数的计算公式本质上是**精确率（Precision）和召回率（Recall）的调和平均数**，选择这种计算方式的核心原因是：**调和平均数对较小值更敏感，能强制 “精确率” 和 “召回率” 必须同时较高时，F1 分数才会高**，从而避免单一指标优秀但另一指标极差的 “虚假优秀” 情况

F1 = 2 * (Precision * Recall) / (Precision + Recall)
常见的平均数有三种：算术平均数（(a+b)/2）、几何平均数（√(a*b)）、调和平均数（2ab/(a+b)）。F1 选择调和平均数，是因为它对 “较小值” 的惩罚更严厉，能强制两个指标必须 “共同提升”

###### macro avg	

 **宏平均：平等对待每个类别**
对所有分类的精确率（或召回率、F1）取**算术平均值**，不考虑每个类别的样本数量差异，即 “每个类别一票，权重相同”

![[Pasted image 20250811204529.png]]
- 优点：对稀有类别（如上述类别 C）更 “公平”，能反映模型对小类别的识别能力；
- 缺点：忽略样本数量差异，当多数类表现好而少数类表现差时，可能高估模型整体性能（反之则低估）
###### weighted avg 

**加权平均：按样本数量分配权重**
对所有类别的精确率（或召回率、F1）取**加权平均值**，权重为每个类别的样本占总样本的比例（即 “样本多的类别权重高，样本少的类别权重低”）
![[Pasted image 20250728102729.png]]
- 优点：更贴合实际业务场景（样本多的类别对整体性能影响更大），适合评估 “多数类为主” 的任务；
- 缺点：可能掩盖少数类的问题（如类别 C 召回率 = 0，但因权重低，对全局指标影响小）


- 若你的任务中**所有类别同等重要**（如识别不同类型的故障，漏检任何一种都严重），优先看 `macro avg`；
- 若**样本多的类别更关键**（如电商商品分类，主流商品识别错误影响更大），优先看 `weighted avg`

###### support



- **K-Means**：
    
    - **最常用**，需要指定聚类的数量 `K`。
        
    - **如何确定K？** 可以使用“肘部法则”（Elbow Method）或“轮廓系数”（Silhouette Score）来辅助选择。
        
    - **优点**：简单、快速。
        
    - **缺点**：必须指定K，且假设簇是凸形的。
        
- **DBSCAN**：
    
    - **不需要指定聚类数量**，而是通过密度来聚类。
        
    - **优点**：能发现任意形状的簇，并能将噪声点（无法归类的特殊样本）识别出来。
        
    - **缺点**：对参数（`eps`, `min_samples`）敏感。如果您的数据中各类别密度差异大，效果可能不好。
        
- **层次聚类**：
    
    - 可以绘制树状图（Dendrogram）来帮助判断分多少类合适。
        
    - **缺点**：计算复杂度高，不适合大规模数据。


- **评估聚类效果**：
    
    - **内部指标**：轮廓系数（值越接近1，聚类效果越好）。
        
    - **外部指标**（如果有一点标注数据）：调整兰德指数（Adjusted Rand Index, ARI）、归一化互信息（NMI）等。但这在纯粹无监督场景下用不了。
        
- **解读聚类结果并为簇命名**：
    
    - 对于每一个聚类簇，您可以**抽样查看其中的文本**。
        
    - **例如**：查看簇0里的100条数据，发现80%都是18位数字，且以110101开头，那么您就可以 confidently 将这个簇标记为 **“身份证号”**。
        
    - 查看簇1，里面大多是“北京市海淀区...”、“上海市浦东区...”，就可以标记为 **“地址”**。
        
    - 这个过程相当于**后验地**为每个簇打上标签。至此，无监督分类就完成了。
