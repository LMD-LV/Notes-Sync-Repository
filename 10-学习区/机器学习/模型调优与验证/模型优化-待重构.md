残差 = 真实销量 - 模型解释的销量

通过残差分析**全面诊断模型的健康状况**，发现：

1. **系统性偏差**：模型是否总是高估或低估
    
2. **异方差性**：误差是否随预测值变化
    
3. **自相关性**：时间序列残差是否存在模式
    
4. **正态性假设**：残差是否符合正态分布


好的模式：残差随机波动，无模式
不好的模式：
1. 趋势：残差随时间增大/减小 → 模型未捕捉趋势变化
2. 周期性：波浪形波动 → 模型未捕捉季节性
3. 异方差：波动幅度随时间变化 → 误差不稳定



### 关键诊断要点

1. **残差随机性**：好的模型残差应像白噪声
2. **无系统性偏差**：残差均值接近0
3. **正态分布**：残差大致服从正态分布
4. **无自相关**：残差间相互独立
5. **同方差性**：残差方差恒定


### 自相关系数（ACF）的作用

自相关系数（ACF）就是用来量化 “今天的残差” 和 “过去第 k 天的残差” 之间的关联程度的工具，取值范围是 `-1 ~ 1`：

- 系数接近 `1` → **正相关**：今天残差高，过去第 k 天的残差也高（比如促销当天残差高，第二天残差也高，说明促销有持续影响）
- 系数接近 `-1` → **负相关**：今天残差高，过去第 k 天的残差反而低（比如周一销量冲高，周二销量回落，残差一正一负）
- 系数接近 `0` → **无相关**：今天的残差和过去的残差没有关联，是纯随机的


时间序列模型的终极目标是让残差成为**白噪声**（纯随机信号），它有三个特征：

1. **均值为 0**：残差没有整体的高估或低估（你的残差均值 = 4.56，接近 0，符合要求）
2. **无自相关**：自相关系数都在置信区间内（你的 `lag=1` 和 `lag=2` 超出了，不符合）
3. **方差稳定**：残差的波动幅度没有明显变化（你的残差波动较大，需要优化）

所有模型训练的优化问题都能转化为无约束 / 带约束的最小化问题，这是判定最优解的前提：

判断是否存在最优解，最核心、最实用的是魏尔斯特拉斯极值定理
机器学习中，只要损失函数是连续的，且通过正则化让参数有界（或无约束时下有界），无论是否可导，都存在最优解。
可导只是能通过梯度下降、解析解等方法求解最优解的充分条件，而非存在最优解的必要条件。

### 损失函数

损失函数: y的值和差值 线 的值最小

例如在销量预测中，可能更关注对销量高峰的准确预测，或者对低估销量的惩罚要比高估销量的惩罚更重，这时就可以通过自定义损失函数来实现这种定制化的优化目标。

L2 正则
对于线性模型（Logistic/LinearSVC），加重 L2 正则项，能抑制极端权重，把单个 token 的影响力拉回均衡



class_weight: 类别权重，balanced表示自动平衡类别权重，让模型在训练时更关注少数类，从而减少类别不平衡带来的偏差

损失函数用于衡量模型预测值与真实值之间的误差，并通过最小化损失函数来优化模型参数。当损失函数最小时，得到的自变量系数就是最优解。

模型的评估和选择

损失函数: 使用损失函数来度量预测偏差的程度
常见的损失函数的计算方式: 0-1损失函数, 平方损失函数, 绝对损失函数, 对数似然损失函数

损失函数负责 “让模型拟合数据”，正则化负责 “让模型别拟合太狠（防过拟合）”，二者结合实现「拟合精度」和「泛化能力」的平衡（偏差 - 方差权衡）。

损失函数（Loss Function）: 量化模型预测值与真实值的偏差（误差），是模型 “学习数据规律” 的目标导向。

正则化:对模型的特征系数（权重w）做惩罚，限制系数的大小，降低模型复杂度，是模型 “防止过拟合” 的约束手段。

损失函数和正则化的互补，本质是在偏差和方差之间找最优平衡：
单独的损失函数：只追求偏差最小 → 模型在训练集上拟合完美，但方差极大（过拟合），对新数据预测误差大；
加入正则化：在损失函数的基础上增加方差惩罚 → 牺牲一点训练偏差，大幅降低模型方差 → 模型在训练集上的拟合稍弱，但对新数据的预测更稳定（泛化能力提升）；
最优状态：组合损失函数最小化时，偏差和方差达到最优平衡，模型泛化能力最强。

网格搜索
一种系统化的超参数调优方法，通过遍历预定义的超参数组合，找到使模型性能最优的参数配置。通过自动化调参避免手动试错，提高效率, 通常嵌套交叉验证，与交叉验证结合以提高调参的可靠性, 对每个参数组合使用交叉验证评估模型性能。

## 自定义损失函数与评价指标

**常见自定义损失函数**：

* **加权均方误差（Weighted MSE）**：在回归任务中，根据业务需求为不同样本分配权重，使误差贡献不均匀。例如，对风险较高的样本赋予更大权重，以减小其预测误差影响。
* **Focal Loss**：主要用于类别极度不平衡的分类问题。它在交叉熵损失基础上引入调制因子，降低“易分类”样本的损失权重，使模型关注难分类样本。Focal Loss 被广泛应用于目标检测（如 RetinaNet）和样本不均衡的场景，有效提升对小众类别的召回率。
* **Huber Loss**：介于平方损失和绝对损失之间的鲁棒回归损失函数，对异常值不敏感。当残差较小时使用平方损失保证平滑，当残差较大时使用线性损失减少对离群点的惩罚。Huber Loss 常用于存在噪声或异常值的回归问题，使模型既兼顾拟合精度又不被极端点主导。
* **分位数损失（Quantile Loss）**：用于分位数回归，通过对残差赋予不同权重来预测指定分位点。例如预测第 90 百分位时，90% 的误差在目标值之下，10% 在目标值之上。Quantile Loss 的公式为：

  $$
  L(y_{pred}, y) = \max\bigl[q(y - y_{pred}), (q-1)(y - y_{pred})\bigr],
  $$

  其中 $q$ 是目标分位数。此损失能训练出**预测区间**而非单值预测，适用于风险评估、金融预测等场景。

**何时需要自定义评价指标**：在实际业务中，模型优化往往需要对特定指标进行精细控制。常见情况包括：

* **业务指标为 AUC/PR**：当目标是排序或置信概率时（如广告点击、欺诈检测），AUC-ROC、PR 曲线下的面积是评价好坏的关键。这些指标本身不可微分，通常作为验证集评价标准，而在训练时可尝试优化近似的目标或调整样本权重以间接提升该指标。
* **关注召回率/特定阈值**：如果业务场景要求低误判率（如重疾筛查要求尽量少漏诊），需调整决策阈值或设计损失函数（例如给FN更高权重）来提升召回率。此时可以自定义损失或通过后处理的方式（如阈值移动）来满足需求。
* **多目标/特定约束**：当需要同时满足多个指标（如在保证精度的前提下最大化覆盖率），可以使用多目标优化技术或设计带惩罚项的损失函数。

**应用示例**：

* 对于极度不平衡的分类任务（如欺诈检测），使用 Focal Loss 能显著提高对少数类的识别率；如果业务更关注高概率召回，可在损失中加大对漏报样本的惩罚。
* 在回归预测中，当某些样本误差代价更高时，可使用加权 MSE；当数据含有异常值时，使用 Huber Loss 能有效降低异常点对模型的干扰。
* 对金融或电力负荷预测等需要估计上下界的场景，使用分位数损失进行分位数回归能同时输出多个置信区间，帮助决策者了解潜在风险。
* 在模型开发过程中，往往使用自定义评价指标（如 AUC、F1、召回率等）来进行超参搜索和早停，以保证模型优化与业务目标一致。


**超参数优化**：调节模型超参数是提升性能的重要环节。主要方法包括：

* **网格搜索（Grid Search）**：需要传入网格字典,对预设的参数网格进行穷举搜索，适用于参数组合较少的场景。缺点是计算量随参数个数和取值增大而指数增长，效率低下。
* **随机搜索（Random Search）**：在超参数空间随机采样指定次数，相比网格搜索更适合高维空间，可覆盖更大范围。实验证明，随机搜索往往比网格搜索在同等计算预算下更快找到较好结果。
* **贝叶斯优化（Bayesian Optimization）**：利用已有评估结果构建代理模型（如高斯过程、Tree-structured Parzen 等），指导下一个超参数的选择。它在选择新超参组合时考虑已有信息，能够高效聚焦于可能的优选区域。常用工具包括 HyperOpt、GPyOpt、Spearmint 等。
* **Optuna**：一种基于贝叶斯优化的开源超参框架，支持自动化算法选择、分布式并行搜索和试验提前中止。Optuna 使用 TPE（Tree-structured Parzen Estimator）算法，不断根据先前的试验结果建议新参数组合，平衡探索未知区域和利用现有优选结果。比如用 Optuna 调优 XGBoost 的学习率、树深、正则化系数等，经常能在较少迭代中找到性能最优的配置。

**正则化与防止过拟合**：为提高模型泛化能力，常用的方法有：

* **L1/L2/ElasticNet 正则化**：在损失函数中加入权重惩罚项。L2 正则化（岭回归）惩罚权重平方，令权重均匀变小，适用于解决多重共线性；L1 正则化（LASSO）惩罚权重绝对值，可使部分特征权重为零，从而得到稀疏模型，有助于特征选择；ElasticNet 同时包含 L1 和 L2 项，可综合前两者优点。例如，使用 L1 正则的线性回归可以自动去掉不重要特征，减少过拟合。
* **早停（Early Stopping）**：在训练时监控验证集指标，若多轮不再改善则停止训练。适用于深度学习等迭代模型，可有效避免在训练集上过拟合。
* **数据增强（Data Augmentation）**：通过随机变换（如图像的旋转、翻转、裁剪）扩充训练数据，使模型见到更多样本，降低过拟合风险。常用于计算机视觉、音频处理等领域。
* **Dropout**：深度神经网络中随机丢弃神经元（及其连接）以降低“协同适应”现象，强制网络学习冗余表达，从而增强泛化能力。Dropout 被证明能显著改善各类神经网络在视觉、语音等任务上的表现（资料显示 Dropout 可随机抑制一部分神经元输出，迫使网络不依赖单一特征，以防过拟合）。

模型求解算法
这里是一个最优化的问题,求增加了正则化项的损失函数最小, 称为结构风险最小化

解析法
如果存在最小值,那么即存在解析解,可求得最优模型的全部参数,也就是解析法
前提为 目标函数必须可导，且导数方程有解析解, 
适用条件较为苛刻；特征维度较大时，矩阵求逆计算复杂度极高。

梯度下降法
一种常用的一阶优化方法，是求解无约束优化问题最简单、最经典的方法之一,是迭代算法，基本思路就是先选取一个适当的初始值, 沿着梯度方向或者负梯度方向，不停地更新参数，最终取到极小值。

梯度下降法计算步骤
（1）初始化参数：随机选择初始参数
（2）计算梯度：在当前参数下，计算损失函数的梯度
（3）更新参数：沿负梯度方向调整参数
（4）重复迭代：直到满足停止条件（如梯度接近零、达到最大迭代次数等）
通过设置梯度,迭代步长(学习率),寻找最优解


梯度方向:函数变化增长最快的方向（变量沿此方向变化时函数增长最快）
负梯度方向：函数变化减少最快的方向（变量沿此方向变化时函数减少最快）
梯度下降不一定能够找到全局的最优解，有可能是一个局部最优解


常见的方法有
批量梯度下降:每次迭代使用全部训练数据计算梯度, 
随机梯度下降: 每次迭代随机选取一个样本计算梯度
小批量梯度下降(最常见):每次迭代使用一小批样本（如32、64个）计算梯度


牛顿法
常见的求解无约束最优化问题的方法, 利用目标函数的二阶导数信息，通过迭代逐渐逼近极值点

牛顿法中需要计算黑塞矩阵的逆H-1，这一步比较复杂；所以可以考虑用一个n阶正定矩阵来近似代替它，这种方法称为“拟牛顿法”
