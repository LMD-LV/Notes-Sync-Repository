
部署方式
1,每个环境占用一个端口,通过hhtp启动,管理服务
2,IPC编程,同一台机器通过绝对路径实现环境隔离
3,使用docker分别安装相关的依赖,最后通过compose启动项目
4,在依赖冲突较小的时候,尝试安装到一个环境中
4,ray+多环境
5,把模型转换为 ONNX 或 TensorRT，然后用 NVIDIA Triton Server 或 ONNX Runtime Serving 托管。Triton 支持多模型、多版本、高并发，能调度 GPU 与 CPU。
6,当需要从主脚本直接调用某个环境下的 python 脚本，可以用 conda run -n envname python script.py 或直接调用该 env 的解释器路径
7,使用如 Airflow 或 Prefect 等框架编排任务，指定每个任务在特定环境中运行。处理复杂、自动化的工作流：考虑方案三（工作流框架）
