1.介绍slot共享组和任务链的概念。

任务链:合并不同算子的SubTask

条件:并行度相同、One-2-One、slot共享组相同、没有禁用任务链

slot共享组:不同算子的SubTask共享Slot

对于一个任务所需要的Slot个数:每个slot共享组中最大的并行度之和

4.介绍一下Watermark,并说明其传递机制。

事件时间:数据中的时间(数据的生成时间)

Watermark:提取到的数据中生成时间,同时可以设置乱序程度

本质:在流中传输的特殊的时间戳数据

作用:处理乱序数据

如何产生作用:延迟关窗

传递方式:广播、短板

生成方式:周期性(默认为200ms生成一次)、断点式(在每条数据后面)
