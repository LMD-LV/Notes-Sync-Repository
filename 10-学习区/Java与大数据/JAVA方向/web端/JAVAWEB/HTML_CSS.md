# HTML

1.  HTML非大小写敏感
2.  超链接标签\<href> 支持绝对/相对 路径，支持 当前窗口，新窗口打开资源
3.  form表单，用户提交信息，向客户端发送，action决定提交服务器地址，method决定方法，input下name 定义参数名，type定义 提交项类型 value为实际的值
4.  get方法的参数作为url后缀的方式 ，post作为方法体的方式提交参数
5.  hidden作为隐藏域的标签一并提交
6.  input作为常用的提交表单项的标签，name定义名称，type为实际的处理动作,常见的有submit，reset等
7.  通过href方式引入资源的时候，可以使用相对，绝对路径来标识地址

# CSS

-   引入CSS，支持 1，在元素中引入 2，在head中 作用范围依赖选择器 3，css文件，使用link外部引入
