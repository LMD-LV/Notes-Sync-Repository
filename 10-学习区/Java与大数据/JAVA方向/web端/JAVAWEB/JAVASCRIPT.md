-   脚本语言，基于对象，弱类型，事件驱动，跨平台
-   ECMAScript，BOM(浏览器对象，和事件相关)，DOM(document对象，和网页动态文档相关) 组成
-   引入方式 内部脚本方式，外部脚本方式
-   数值类型为number 不区分整数浮点数，boolean中 非零数字，非空字符串都会是为 true
-   比较符号有 ==和 ===
-   事件触发，用户行为（鼠标，键盘，表单），代码自动 ---DOM编程
-   BOM是浏览器对象模型，是各个浏览器的API，可通过其实现会话级别，持久级别数据存储
-   DOM 用于实现文档的动态修改，数据，样式动态变化
