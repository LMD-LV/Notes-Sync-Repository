单体架构 一个tomcat部署的服务同时管所有的业务，融合了spring，springmvc，mybatis，简称ssm

分布式架构，不同的模块分布在不同的机器上，使用springboot简化配置，springcloud调度，每个模块的本质还是ssm

目前ssm中设计的 组件流程，controller，service，dao三层

配置文件，xml，注解，java类

xml文件头的信息为约束，因为xml文件的标签可以自定义，所以要符合spring的相关要求

vo是后端返回的前端数据，会设计多个POJO的字段组合，计算等

dto是从controller向mapper层传递数据的时候，因为数据安全，对外提供的不是一个对象的全部属性，dto相当于mapper层对象的部分属性组成的对象

序列化的主要目的是将对象转换为可传输或存储的格式，当传输数据的时候，如果是原生支持的数据类型(基本类型)，框架自动处理的(JACKJSON)，当使用Java原生RMI、Socket直接传输对象或需要持久化到文件时，必须实现Serializable接口(目前我对这个了解仅为，自定义的pojo需要传输的时候，持久化的时候，需要实现序列化，中间有些敏感字段不传输)
