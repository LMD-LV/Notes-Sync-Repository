## 设计风格

## java

-   代码中仅依赖 JDBC 接口（如 java.sql.Connection），这些接口是 Java 标准库（rt.jar）的一部分。驱动实现类（如 com.mysql.jdbc.Driver）通过反射动态加载（如 Class.forName()），编译时无需直接引用。

## 开发时候注意点

-   凡是协议，都要考虑超时时间，断点重连，重连机制
-   凡是数据的格式化处理，都要考虑到异常数据的处理格式问题

## 分布式通识

###### 数据一致性

强一致性: 数据主从同步的时候，保证读取到正确数据，但是因为同步，可能出现延迟，阻塞等，

最终一致性：保证能读取到数据，但是可能不是最新的数据，需要设置补偿机制保证最后的一致
