CPU运行大模型的主要瓶颈是内存带宽和容量，其次是计算能力（指令集）。CPU核心数影响并行度，但内存带宽才是决定性因素。通常7B-13B的量化模型可以在16-32GB内存的CPU上运行，14B可能需要更多内存和耐心。

模型必须能完整装入物理内存，否则会因 OOM（Out of Memory）崩溃。

可用内存 ≈ 模型文件大小 + KV Cache 大小 + 系统开销

KV Cache 大小取决于 上下文长度 和 量化方式。
CPU 运行大模型本质是大规模矩阵向量乘，每生成一个 token 都需要遍历整个模型权重。
生成速度的理论上限 ≈ 模型大小 / 内存带宽。

CPU 运行 14B 以上模型理论上可行（32GB 内存下加载 Q2 量化版），但速度会降至无法接受的程度，因此通常认为 13B~14B 是 CPU 的实用上限，前提是支持 AVX2。
