### Python 代码保密性处理（浓缩精简版・替换为免费工具）

## 一、核心前提

Python 为解释型语言，无原生编译加密特性，需根据保密需求 + 部署场景选择方案，所有方案均兼容一键启动脚本。

## 二、分级加密方案（按 成本↓ / 保密强度↑）

### 🔹 基础级（低成本 | 内部项目 / 防无意查看）

**.pyc 字节码编译**

原理：源码转二进制字节码，删除.py 直接运行.pyc

命令：`python -m compileall -b 项目目录`

优缺点：零成本、易反编译，仅防随手查看

**代码混淆**

原理：修改变量名 / 打乱结构，增加阅读难度

工具：pyminifier（轻量）、yobfuscate（进阶免费）

优缺点：兼容原生代码，可被反混淆，适合内部使用

### 🔹 进阶级（零成本 / 中成本 | 对外交付 / 商业项目）

**yobfuscate 加密（免费首选）**

原理：开源代码混淆加密，支持机器绑定、时间授权限制，**完全免费商用**

命令：`yobfuscate main.py -o dist/`

优缺点：零成本、无功能限制、易上手，加密强度满足商用基础需求

**Nuitka 编译加密（高强度）**

原理：Python 代码直接编译为机器码二进制文件，无法反编译，支持自定义授权管控

命令：`python -m nuitka --onefile main.py`

优缺点：**极高保密、免费开源、跨平台**，编译速度稍慢，无任何版权限制

### 🔹 高级级（高成本 | 核心算法 / 商业软件）

**打包可执行文件**

工具：PyInstaller，打包为单文件 exe/elf，无源码暴露

命令：`pyinstaller -F main.py`

优缺点：无需 Python 环境，体积大

**云化 API 部署**

原理：核心代码不上线，仅对外提供接口调用

优缺点：绝对安全，依赖网络、需运维

**Cython .so 编译**

原理：核心代码编译为二进制 C 扩展库

优缺点：极致保密、提升运行效率，适合核心算法加密

---

## 三、实战最优组合方案（一键启动适配）

**核心逻辑 Nuitka 编译 + 通用代码 yobfuscate 加密**

拆分项目：核心算法 / 业务 + 通用启动 / 配置

核心模块用 Nuitka 编译为二进制，通用模块用 yobfuscate 加密

编写 `start.sh/start.bat` 一键启动脚本

服务器仅保留编译 / 加密文件 + 脚本，删除原始.py 源码
