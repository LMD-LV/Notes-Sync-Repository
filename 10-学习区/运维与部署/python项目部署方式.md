#关键技术栈 Conda-Pack 离线环境打包方案

Conda 环境专属**绿色离线打包工具**，将整个 Conda 环境打包为独立压缩包，是内网 / 无 Root / 无外网服务器迁移 Python 环境的**首选方案**。

## 二、核心特点

1. **打包完整性**
    自动包含 Python 依赖、C/C++ 扩展库、CUDA 相关底层库，适配深度学习 / 科学计算场景。
2. **使用便捷性**
    自动处理环境路径偏移、硬链接问题，解压即用，目标机**无需安装 Conda**。
3. **兼容性**
    仅要求开发机与目标机：
    - 同为 Linux 系统
    - CPU 架构一致（x86_64 / ARM64）
    - GLIBC 版本差距较小（麒麟 V10 兼容良好）

## 三、完整操作流程

### 🔹 开发机（外网，环境准备 + 打包）

1. 创建干净环境

    ```
    conda create -n my_env python=3.11
    ```
    
2. 安装项目所有依赖（torch、CUDA 相关等）
    ```
    pip install torch scikit-learn ...
    ```
    
3. 安装 conda-pack
    ```
    pip install conda-pack
    ```
    
4. 执行打包
    ```
    conda pack -n my_env -o my_env_packed.tar.gz
    ```

### 🔹 目标机（内网，解压 + 使用）

1. 上传压缩包至服务器
2. 解压环境
    ```
    mkdir -p my_env && tar -xzf my_env_packed.tar.gz -C my_env
    ```
    
3. 激活环境
    ```
    source my_env/bin/activate
    ```
    
4. 直接运行代码，无需额外安装依赖

- 深度学习模型离线部署
- 科学计算环境迁移
