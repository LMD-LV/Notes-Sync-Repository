
## Python部署

操作系统差异(Windows,linux)
* Windows 的 Python 包底层调用的是 `.dll` (动态链接库) 和 Windows API Windows 包通常包含：`win_amd64` (x86) 或 `win_arm64` (ARM Windows)
* Linux 的 Python 包底层调用的是 `.so` (共享对象) 和 Linux Kernel API Linux 包通常包含：`manylinux_aarch64` 或 `linux_aarch64`

架构位数差异决定了“指令集”
X86架构
Arm架构
现在的 AI 模型（PyTorch, TensorFlow, LLM 等）几乎 100% 强制要求 64 位环境。32 位系统不仅内存受限（最大 4GB），而且现代计算库根本不提供 32 位版本。


Python的版本差异
Python 的 C 扩展模块（C-Extension）是和特定版本的 Python 解释器编译在一起的


Glibc 版本
`glibc` 是 Linux 最底层的 C 运行库
 你必须确保下载的包要求的 glibc 版本 **<=** 服务器上的 glibc 版本（向下兼容）。
