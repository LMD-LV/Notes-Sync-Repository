# 典型回答

  

InnoDB存储引擎支持多种数据格式，包括：

​  

1.  COMPACT格式：是MySQL 5.0之前的默认格式，数据行中只保存字段值，利用空值列表保存null值，也不保存任何其他信息，因此数据文件相对较小。这个格式不再被推荐使用。

  

2.  REDUNDANT格式：相对于COMPACT格式增加了一些额外的信息，用于更快的定位到数据行的位置，增加了一些冗余信息，相对于COMPACT格式，它的性能略有提高，但是占用的磁盘空间也略有增加。

  

3.  DYNAMIC格式：相对于REDUNDANT格式增加了行头信息的变长字段，使InnoDB支持更多的行格式。这个格式可以存储比REDUNDANT格式更多的数据类型，如VARCHAR和BLOB等。

  

4.  COMPRESSED格式：是MySQL 5.1中InnoDB的新特性之一，它可以在存储数据时对数据进行压缩，从而减小磁盘占用空间。它的缺点是增加了CPU的使用，可能会降低一些查询的性能。

  

5.  Barracuda格式：是MySQL 5.7引入的一种新格式，相对于前面的格式，支持更多的高级特性，如动态行格式、行级压缩、空间管理等。
