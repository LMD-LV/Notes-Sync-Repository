# 概念

**FreeIPA：**集中式的身份验证和权限管理的解决方案，组织和企业可以更方便、更安全地管理用户的身份信息和访问权限。FreeIPA服务分为IPA-Server和IPA-Client两个部分。IPA-Server需要单独准备一台服务器进行安装，而IPA-Client则需要在管理的所有集群节点服务器上安装。FreeIPA可直接管理各组件的访问，若是需要对数据库的库表以及字段级权限控制，需要数据库集成或自定义扩展。

**Kerberos：**一个身份验证协议，用户登录认证（kinit）到FreeIPA的域时，会收到一个加密票据（临时身份证），用户可在一段时间内使用票据在整个域（hdfs、hive等）中进行身份验证。

**身份验证：**FreeIPA使用Kerberos作为其身份验证（组件级）机制。

**LDAP：**一个轻量级目录数据库，用于管理用户和组的信息。

**访问策略：**FreeIPA中制定，只有满足访问策略的用户才能访问相关资源。

**整体理解：**FreeIPA是总指挥，负责整合和管理整个系统（Web UI、CLI和API等方式增删改用户/组信息,日志审计等）；LDAP是数据存储后端，存储用户、组的身份信息；Kerberos是验证前端，负责验证用户的身份和权限，主要是针对组。
