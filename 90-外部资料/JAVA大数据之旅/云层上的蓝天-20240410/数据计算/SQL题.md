from(

,series

,substring(act\_dt,1,7) act\_ym

,sum(sum(deliver\_cnt)) over(partition by deliver\_ym,country,brand,series) month\_total\_deliver\_cnt

,datediff(to\_date(substring(act\_dt,1,7),'yyyy-mm'),to\_date(deliver\_ym,'yyyy-mm'))+1 act\_order\_month

,sum(act\_cnt) act\_cnt

\-- 激活率

,sum(act\_cnt)/sum(sum(deliver\_cnt)) over(partition by deliver\_ym,country,brand,series) act\_rate

from ts\_deliver\_act\_table

group by deliver\_ym

,country

,brand

,series

substring(act\_dt,1,7)

) t1

group by deliver\_ym

,month\_total\_deliver\_cnt

,country

,brand

,series

# 预测逻辑

根据要预测的国家+品牌+系列，取预测月份往前18个月的历史激活数据作为样本，得到前18个月发货后每个顺序月的激活数据，如上图所示

比如我要预测202408月发货一万台手表，则要取202408的前18个月的数据，则是2023-01至2024-07，对于每个激活顺序月，都有18个样本，计算202408发货后第一个月的激活量，则取2023-01至2024-07这些批次的每次的第一个月的激活率，然后取掉一个最大值一个最小值，做平均，则是预估的202408的一个月激活率

以上图为例，则是取F列的数据,取掉最大值96.71%，最小值4.46%，再平均得到56.65%，则认为202408这一批在发货后的第一个月的预计激活率是56.65%。

需要注意的是如果所选的样本量低于6个，则不去掉最大最小，比如我现在是202408，我计算的发货后第十八个月的激活率，则要取上表中W列来计算，但是W列有样本的数量只有3个，所以这里不去最大最小值，直接求平均，比如说得到15%，则202408这一批在发货后的第18个月预计激活率是15%
