# 1.rm -rf / 最简单的删库命令，直接删文件，但公司有可能花钱做数据恢复，数据理论上可以救回来

# 2.磁盘删除原理

大部分文件系统，删除并不是真的把数据块都给删掉，为了提高速度，会把文件所在块打上删除标记，就像数据库里逻辑删除一样，逻辑删除后，只要通过恢复软件，将哪些块的删除标记去掉，这样文件就恢复了

# 3.通过dd命令的操作

dd命令用于将对应的文件，块存储写入对应二进制数据，

特殊的输入设备:/dev/random,/dev/urandom产生随机数

/dev/zero产生数字0

dd if=/dev/zero of=你的磁盘块文件 将你的目标磁盘全写成0，这样数据全被覆盖了，连标志位都变0了，就没法恢复了

dd if=/dev/random of=你的磁盘块文件 将你的目标磁盘全写成随机数，最后能产生啥效果，谁也不知道了
